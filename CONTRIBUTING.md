# Contributing

We welcome contributions! Here's how to help:

## Adding a Tool

1. Fork the repository
2. Add your tool to the appropriate section
3. Include a brief description
4. Submit a PR

## Guidelines

- Tools should be actively maintained
- Include official links when possible
- Keep descriptions concise
- Follow alphabetical order within sections

## PR Process

1. Create a feature branch
2. Make your changes
3. Submit a pull request
4. Wait for review

Thank you for contributing!
